# Bowl images (real / AI-generated)

Drop product photos here, then set the `image` field on the matching product
in `lib/site.ts` (e.g. `image: "/bowls/fruit.jpg"`). The menu card will render
the photo automatically instead of the SVG illustration — no other code changes.

Suggested filenames (square, ~1000×1000, .jpg or .webp):
  fruit.jpg       → Zen Fruit Bowl
  power.jpg       → Zen Power Bowl
  balance.jpg     → Zen Balance Bowl
  signature.jpg   → Zen Signature Bowl
  ragi.jpg        → Ragi Java

All images must be ORIGINAL (your own photos or AI-generated) — do not use
another company's photography.
